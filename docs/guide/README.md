# MMU Display user guide

## What it is and why

MMU Display is a touchscreen that sits beside your printer and shows its
multi-material unit: the bays, their spools, the groups, loads, alerts, drying
and settings. You can load, unload, change a bay's group and edit spool facts
from it, without opening a browser.

The same views also run as a panel inside Mainsail and Fluidd, so the screen
on the printer and the page on your desk show one thing in one language.

One C core (`src/model`, `src/backend`, `src/view`) holds the logic. Three
renderers draw it:

| Renderer | Where | Source |
|----------|-------|--------|
| LVGL screens | ESP32 display, 480x320 | `src/ui`, `platform/esp32` |
| Desktop simulator | your computer, for development | `platform/sim` |
| Vue 2 web panel | Mainsail and Fluidd | `web/vue`, generated by `tools/gen_host.mjs` |

A TypeScript twin of the core (`web/logic`) is kept identical to the C core by
differential tests. A button in the browser and a tap on the display run the
same code path.

The display talks to Moonraker over Wi-Fi. It needs the OpenAMS plugin on the
printer, which publishes one `openams_ui` object per unit. It holds no printer
state of its own, so unplugging it costs you nothing but the view.

## Quick path

1. Get a supported board ([hardware.md](hardware.md)).
2. Flash it with ESP-IDF ([flash-and-setup.md](flash-and-setup.md)).
3. Type three commands over the serial console: `wifi`, `moonraker`, `unit`.
4. Tap four targets to calibrate the touch.
5. Optional: install the panel into Mainsail or Fluidd ([web-panel.md](web-panel.md)).
